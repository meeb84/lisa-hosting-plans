## 9929 和 4837，到底差在哪里？

这是“丽萨主机套餐”搜索里最值得解释的一组差异。

### 9929 更像“线路 + IP 属性”的组合

美国 9929 一期当前官网明确写的是洛杉矶、国际精品网络、双 ISP 家宽住宅 IP，并提供从 1 核 1G 到 4 核 4G、从 1TB 到不限流量的不同档位。官网还特别提示，部分 IP 段因为 IP 提供方要求**禁止 ping**，不能 ping 并不等于服务器不能用。

对于真正关心 IP 属性的人，这类套餐的主要成本并不只是 CPU 和硬盘，而是 IP 资源本身。因此，拿 68 元的 9929 住宅套餐去和十几二十元的普通数据中心 VPS 直接比“谁配置更多”，意义并不大。

反过来，如果你只是部署 WordPress、个人博客、测试 API 或跑一个小型服务，那么住宅 IP 的额外成本未必有实际价值。

### 4837 的优势更直接地体现在带宽

4837 这一条线当前官网的基础版已经给到 **300Mbps + 3TB**，进阶版 500Mbps + 8TB，豪华版 1Gbps + 20TB；两档不限流量产品分别是 200Mbps 和 500Mbps。

所以看套餐时，不要看到“9929”“4837”就只按名字判断。真正应该看的是：

**IP 属性 → 带宽 → 月流量 → CPU/内存 → 计费周期。**

对大流量传输、视频、文件分发这类需求，4837 的规格表会更容易看出差异；对 IP 属性更加敏感的场景，则要进一步确认具体套餐是不是双 ISP 住宅 IP，而不能把所有“原生 IP”理解成同一种东西。

## 住宅 IP、原生 IP、双 ISP，不是一回事

很多第三方文章把这几个词写得非常接近，甚至直接互换。实际看官网套餐名称，会发现丽萨主机自己也把它们分成不同产品线。

例如：

美国 9929 一期直接标明“双 ISP 家宽住宅 IP”；美国静态住宅 IP VDS 则强调美国家庭宽带静态住宅 IP；台湾 Hinet 产品明确写的是动态住宅 IP；日本 IIJ 方案则把运营商 IIJ、双 ISP、住宅 IP 和 VDS 分开描述。

因此，“原生 IP”这个词本身不足以决定套餐值不值得买。购买前至少要确认三件事：

1. IP 是普通数据中心原生 IP，还是住宅/ISP 属性 IP。
2. 是静态 IP 还是动态切换 IP。
3. 产品是否属于特殊退款规则。

特别是台湾、德国、日本部分 VDS，官网明确标注某些方案属于特殊产品，退款不是普通的原路退款，而是仅退网站余额。

## 不限流量不等于“随便跑满带宽”

这一点在丽萨主机的套餐表里尤其明显。

例如美国 9929 不限流量 Lite 是 **20Mbps**，Pro 是 **50Mbps**；香港 CMI 不限流量 Lite/Pro 分别是 **30Mbps / 50Mbps**；日本 IIJ 不限流量 Lite/Pro 是 **100Mbps / 200Mbps**。

也就是说：

> **不限流量解决的是“流量额度”问题，不是“带宽无限”问题。**

假设同样写着“无限流量”，50Mbps 和 200Mbps 的实际使用能力完全不同。持续传输、直播、下载、视频处理之类场景，带宽往往比“流量不限”更值得优先看。

美国 CN2 GIA 不限流量系列则更极端：官网当前公开了 **1Mbps、2Mbps、5Mbps、10Mbps、20Mbps** 五档，价格从 30 元/月一路到 1999 元/月。

这个系列很适合拿来说明一个常见误区：**“不限流量”不是一个性能指标，它只是计费维度之一。**

## 亚洲节点应该怎么理解

### 香港

香港目前至少可以看到三类明显不同的套餐：三网 CMI/CU2/CN2、iCable 双 ISP 住宅、HGC 双 ISP 住宅。

CMI/CU2/CN2 方案明显偏向大陆访问优化；iCable 和 HGC 则更偏向住宅 IP 属性以及香港本地服务。官网对 iCable 和 HGC 都写有香港本地服务、流媒体以及住宅 IP 等用途说明。

所以香港不是“选一个香港 VPS 就一样”。如果你在意的是中国大陆访问延迟，线路信息更重要；如果你在意的是香港本地网络身份，则应该看 iCable/HGC 这类住宅 IP 产品。

### 日本

日本的产品差异更明显：原生 IP 大带宽 VPS、ISP 静态住宅 IP VDS、IIJ 双 ISP 住宅 VDS 是三种不同定位。

IIJ 页面明确写有 AS2497、双 ISP 原生住宅 IP，并列出了 DMM TV、TVer、Niconico 等日本本土服务的解锁场景；同时也明确提示非大陆优化网络，建议中转。

而日本原生 IP 大带宽 VPS 的低档价格只有 88 元/月，豪华 300 元/月，不限流量从 598 元/月起。

如果你的核心诉求是“日本 IP + 大带宽”，不需要住宅属性，直接看原生 IP VPS 往往更容易控制预算。

### 台湾

台湾产品可以分成原生 IP VPS、Hinet 动态住宅 VDS、原生 IP VDS 三块。

Hinet 动态住宅产品目前是 399/599/899 元/月三档，并且全部不限流量；台湾原生 IP VDS 则从 299 元/月起，最高 1599 元/月。

官网还特别提醒，台湾 BGP 国际网络**并非中国大陆直连优化线路**，部分联通和移动用户直连表现可能不同，并建议根据情况使用香港或日本中转。

这类提示其实比“流媒体全解锁”更有购买参考价值，因为它直接关系到中国大陆用户实际怎么接入。

## 年付到底有没有意义？
